VibeSync: Installation and use

Windows
Run VibeSync-Setup-<version>.exe and follow the installer. VibeSync starts
automatically afterwards and offers to connect Spotify on first launch.
Without installing: run VibeSync-Portable.exe directly.

Linux x86_64
Debian, Ubuntu, Mint and Pop!_OS: double-click the .deb to install it, or run
  sudo apt install ./VibeSync-Linux-<version>.deb
The .deb adds a menu entry and installs pactl and parec automatically.
Other distributions: run the install script next to the AppImage:
  sh install-linux.sh
It installs VibeSync for the current user, adds a menu entry and the vibesync
command, detects missing FUSE and offers to install missing audio packages.
Uninstall: sh install-linux.sh --uninstall

Connect Spotify
You need Spotify Desktop with Spicetify (https://spicetify.app).
In VibeSync, open Settings > Spotify > Spotify bridge setup and click
Install bridge (also offered in the welcome dialog). VibeSync copies the bundled
bridge, enables it and runs spicetify apply; Spotify restarts once.
If Spicetify is missing, Get Spicetify opens the instructions; click Check again afterwards.
The bridge connects automatically and supplies title, all available artists,
album, cover, playback time, duration, pause, Up Next and Spotify lyrics.
Spotify Desktop must be running with the bridge. There is no Client ID or OAuth sign-in.
Audio is still captured from the computer.

Visualizer and lyrics
There is one visualizer. Colors and effects are under Settings > Visualizer and Colors.
Album Art adapts the colors to the current cover.
Long artist lists wrap for the current song and in the preview.
Up next appears in the lower right. Turn it off under Settings > Spotify > Show next song.
The local queue updates about once per second. Without a next song the preview stays hidden.
For Spotify lyrics, install the bridge as above and turn on Show lyrics.

Updating
Windows: run the new Setup installer; it replaces the old version.
Linux: install the new .deb, or run sh install-linux.sh again with the new AppImage.
Existing VibeSync settings are kept. See UPDATE.txt for details.
The app has no automatic update feed configured.

Diagnostics and origin
Settings > About shows runtime information and opens the log folder.
VibeSync is Shady's fork of VibeDeck, created by Amara Dhanush Kumar.
The MIT license and the notices for Electron and the audio helper are preserved.

Keep screen awake
Settings > General > Keep screen awake is on by default. It only applies while the main VibeSync window has focus. Other active windows, minimizing and the tray release the lock.
